A newspaper front page that sums up Tuesday 17 November 2026 in a single
image: Ukraine strikes the Kerch bridge a second time, oil tankers hit mines
off Hormuz, Xi, Trump and Putin are set to meet in Shenzhen, Europe plans a
Rwanda return hub, and the US moves to close an AI-chip loophole — plus an
"ALSO" strip with the day's other stories.

The image is drawn deterministically by `gen.py` (Pillow, fixed seed, no
network, no timestamps) and written to `entry.png` (1024×1024). `main.ts`
copies `entry.png` into `$MAKEFUN_OUTPUT_DIR`.
